# 星辰界正式版首期设计

日期：2026-11-24

## 目标

将现有单文件概念原型演进为 Astro + React Three Fiber 的可扩展个人站首期。首页以星海作为空间导航，首批提供日常、技术、播客三个栏目；访客能预览栏目并通过短暂跃迁进入栏目内容。

沿用项目既定表达：宇宙负责空间与导航，蛊的世界观负责命名与叙事。定仙游蝴蝶继续作为导航意象。参考 GitHub 上成熟 3D 项目的星系生成、相机编排和性能处理方法，使用许可清楚的开源依赖，不复制无许可模板的实现或视觉资产。

## 首期范围

包含：
- Astro 静态站骨架与首页。
- 一个客户端 React Three Fiber 场景，包含程序化星海、三颗栏目星、轻量尘埃和栏目标签。
- 数据驱动的栏目配置，至少包含标题、slug、蛊名、颜色、坐标、简介与内容入口。
- 悬停/键盘聚焦预览；点击或键盘激活后约 1.5 秒跃迁并打开内容面板。
- 面板关闭与 Escape 返回星海；栏目入口同时提供语义化 HTML 链接。
- 手机布局、减少动态效果支持，以及 WebGL 不可用时的静态星图/栏目列表降级。
- 首期说明文档，记录开源依赖与许可证核验结果。

不包含：
- 真实文章迁移、播客 RSS/音频播放器、评论与搜索。
- 蝴蝶模型重制、书虫/修为/养蛊等第二相玩法。
- 用户账号、内容管理后台或服务端 API。

## 用户流程与交互

1. 首页先显示站名、简短说明和三颗可访问的栏目入口；星场缓慢运动，栏目星保持清晰可辨。
2. 指针悬停或键盘聚焦某个入口时，显示栏目标题、蛊名和一句摘要，提供目的地预览。
3. 激活入口后，定仙游引导镜头进入目标星。桌面端可使用短时镜头推进、粒子运动与克制的辉光；总时长约 1.5 秒，动画结束后进入对应的静态栏目路由。
4. 栏目路由包含栏目介绍、内容列表占位和“返回星海”链接；浏览器返回也能回到首页。首页跃迁期间按 Escape 可取消跃迁并回到星海。
5. 若系统启用减少动态效果，直接淡入栏目内容，不使用快速镜头、闪白或强烈模糊。
6. 手机上降低粒子数与后处理，保留触摸入口；场景无法运行时以同一栏目数据渲染静态导航。

## 视觉方向

- 背景近黑蓝，沿用原型的金色、青色、淡紫与播客品红点缀。
- 三颗星在空间中有前后层次，栏目标签保持真实 DOM 文本以确保清晰度和可访问性。
- 星体用程序化几何/材质表达，不依赖外部商业模型或官方插画。
- 光效集中在星体与跃迁阶段，避免常驻高强度后处理。
- 蝴蝶沿用已有 Canvas 2D 概念资产作为过渡期视觉元素；其渲染与 R3F 场景通过明确的状态/目标坐标接口衔接。

## 架构

- Astro：负责静态页面、基础 SEO、站点元信息与无 JavaScript 的栏目入口。
- React 岛：只承载需要交互的首页星场；其余内容留在 Astro 页面层。
- Three.js / React Three Fiber：场景生命周期、相机、粒子与星体渲染。
- Drei：仅引入实际使用的基础辅助组件。
- postprocessing：用于跃迁阶段的轻量效果；设备/偏好降级时关闭。
- 栏目数据：集中在独立配置文件中，渲染层不内嵌文章正文。每个栏目使用稳定 slug，未来可映射到 Astro 内容集合和独立路由。
- 场景状态：用小型状态机管理 idle、preview、travel、arrived、return；动画由单一场景控制器协调，动画完成后导航至独立的 Astro 静态栏目页。
- 兼容层：以 CSS/HTML 栏目导航作为可靠入口，WebGL 场景只是增强层。场景初始化失败时展示静态星图与同一份导航数据。

## 性能与可访问性

- 首屏优先显示标题与栏目入口；场景可以延后初始化，并在不可见时暂停动画。
- 使用实例化/批处理绘制重复星点；按视口与设备能力调整粒子量和 DPR。
- 移动端关闭或减少 Bloom、色差、径向模糊等后处理。
- 尊重 prefers-reduced-motion；所有栏目可由键盘访问，焦点样式清晰，Escape 关闭面板。
- 星场为装饰性画面时使用适当的无障碍隐藏策略，重要文字始终由 DOM 提供。
- 页面需有 WebGL 初始化失败的可读提示和直接栏目入口。

## 错误处理

- WebGL 上下文创建失败、浏览器不支持或设备丢失上下文时，切换为静态导航，不阻断栏目访问。
- 场景资源/后处理加载失败时先禁用可选效果，再保留基础场景。
- 栏目数据按启动时校验必需字段；无效条目不渲染为 3D 目标，并记录开发期错误。
- 页面 URL 使用栏目 slug 表示目标；直达栏目时仍呈现可读栏目内容，不要求先完成 3D 动画。

## 开源项目与许可

优先使用 npm 正式发布、许可证明确的库：Astro（MIT）、three.js（MIT）、@react-three/fiber（MIT）、@react-three/drei（MIT）、@react-three/postprocessing 与 postprocessing（按实际锁定版本核验）。具体版本在实施时根据兼容矩阵锁定，并保存依赖锁文件。

参考项目包括 Bruno Simon 的 folio-2019、HamishMW 的 portfolio、0xFloyd 的 Portfolio_2020、terryHu7 的 homecraft，以及星系生成示例。只从许可证允许的仓库借鉴算法、交互组织或公开 API 用法；不把无许可证或 NOASSERTION 仓库的代码和资产复制进产品。实施时记录访问链接、许可证、实际借鉴内容与版本/提交。

## 验收标准

- 首页可以在桌面与手机视口访问三个栏目入口。
- 悬停/聚焦会显示目的地预览，鼠标、键盘激活都能进入栏目面板。
- 跃迁结束后进入正确栏目路由；栏目页返回链接和浏览器返回能回到首页，首页 Escape 能取消跃迁。
- 减少动态效果时仍可完成栏目访问且无快速跃迁。
- WebGL 不可用时仍可通过静态栏目导航访问内容。
- 栏目配置与场景代码分离，新增栏目不需要改星体渲染逻辑。
- Astro 生产构建成功；检查桌面/移动布局与浏览器控制台无运行错误。

## 验证方式

实施阶段运行项目生产构建，并进行浏览器手动检查：默认首页、预览与跃迁、返回、键盘操作、减少动态效果、窄屏布局，以及 WebGL 降级。验证开源依赖许可证与锁文件版本。
