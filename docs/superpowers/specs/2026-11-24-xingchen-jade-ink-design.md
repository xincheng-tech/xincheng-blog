# 星辰界青玉蝴蝶与墨韵背景设计

## 目标

让首页的定仙游成为小巧、精致、像青玉透光的蝴蝶；在现有暗色星海里融入少量墨迹与纵向书法，增强洒脱气质但不改变星海导航的主次。跃迁的相机、蝴蝶和页面导航使用同一时序，抵达时再进入栏目页。

## 设计决定

- 只保留一种蝴蝶风格：青玉。原型 `demo/index.html` 不修改，React Canvas 版本保留四翅轮廓但改为更轻薄的玉绿与暖白描线、透明翼膜和少量流动光丝；减少大面积霓虹光晕与粒子。
- 桌面蝴蝶约为原显示尺寸的 60%，窄屏继续收小；桌面悬停时轻盈浮动，跃迁时沿弧形轨迹加速、减速并在目标点消隐。
- 首页背景继续以深蓝星空为底。墨痕和竖排短句只出现在边缘，使用低对比、柔和渐隐；中心标题、栏目入口与蝴蝶路径保持清晰。不得将参考图中的人物、插画或原字样复制到站点。
- 星体相机用 1.6 秒缓动 Bézier 路径完成跃迁，固定时长与导航计时匹配；Escape 取消时回到星海。减少动态效果时保持直接导航。

## 范围

修改 `src/components/ButterflyGuide.tsx`、`src/components/UniverseExperience.tsx`、`src/components/StarfieldScene.tsx`、`src/styles/global.css` 和首页 `src/pages/index.astro`。仅新增程序化 CSS/SVG 风格层，不添加依赖或外部图片。不得修改 `demo/index.html`。

## 验收

- 蝴蝶在首页仍呈青玉色、尺寸明显小于当前版本，细节轻透而不以整团霓虹压住星体。
- 墨迹只作为边缘低对比背景，首页中心和栏目入口仍清楚。
- 鼠标预览、跃迁及 Escape 返回动作有连续的缓入缓出；栏目跳转只在相机飞行结束后发生。
- 原型文件与其他首页功能保持不变；GitHub 中的旧功能分支保留，新增专用功能分支与提交可通过 GitHub Revert 回退。
